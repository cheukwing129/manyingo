## 新的題目標準

1. **證據在題內。** 指代對象、必要人物、事件起點及比較對象須在作答前可見；篇名、作者名與事後解說不能代替證據。
2. **保留學習，避免題外記憶。** 學生仍可學習新詞與句法；不要求每道詞義題都能靠常識猜中。新知應有短提示／示例，不能因未記得課文人物而降低語言掌握度。
3. **以意思和用法為主。** 優先問「誰做甚麼」「這句在說甚麼」「如何換成另一個語境仍能理解」，再把術語作補充。認出「賓語前置」不等於已能理解句子。
4. **使用最短足夠語境。** 基礎題多用一至三句；只有必要時才增加短段。避免每題都附整篇課文，增加手機閱讀負擔。
5. **解說指出線索。** 說明「哪個詞／哪句提供證據、如何排除另一理解」，不能只說「根據課文可知」。
6. **加入真正換語境的驗證。** 熟句教過後，用來源不同的句子驗證同一技能；多次辨認同一句的不同問法不能等同可遷移能力。

## 另需處理的內容

- **4 題明確考原句記憶**：`q008`、`cap1q004`、`cap1q005`、`cap1q006`。目前均屬 `set-text`，不是正常核心題；不應拿來當文言語言主線成效。`ad3q002` 亦屬同一名句知識點，但有白話意思與完整選項，比直接默寫更接近語意配對，應分開評估。
- **課文主旨及情節題**：例如 `p2q012` 問《岳陽樓記》一悲一喜的結構作用、`p2q042` 問曹劌認為可一戰的根本條件。現有分流已把它們放到 `set-text`；若保留為閱讀訓練，必須先提供足夠材料，再評估能否依文本推理。
- **術語偏重**：如 `q005` 直接問「廉頗者，趙之良將也」是甚麼句式。不是錯題，但可先問哪個白話意思準確，學會身分判定後才介紹「判斷句」。
- **中度語境問題**：`tr5q016` 仍可由句法判斷要補「勸諫對象」，但答案額外引入未提供的「藺相如」；`stl2q024` 能辨認比較格式，但正確選項額外補入「可畏／強大」這個未明說的比較尺度。應精簡超出題內證據的資訊，或補足背景。
- **另有說話者誤標**：`p2q043` 題幹把「小惠未遍，民弗從也」寫成魯莊公所說；這是曹劌的回應。考「遍」的字義不需要記說話者，可直接刪除錯誤身分標示。

## 使用者例子的改寫示範

**原題**：「刻唐賢今人詩賦於其上」中的「其」指代甚麼？

**建議改寫**：讀句子：「乃重修岳陽樓，增其舊制，刻唐賢今人詩賦於其上。」最後一個「其」指甚麼？

- 岳陽樓
- 詩賦
- 唐代賢人
- 當代文人

**解說方向**：前面先提出「岳陽樓」，後面接連說擴建和刻詩；「於其上」交代刻詩的位置，故回指這座樓。學習重點是追蹤代詞與動作關係，不必預先讀過《岳陽樓記》。上列為待套用示例，正式提交前仍須核對標點與干擾項。

下一次驗證同一技能應換另一段有清楚先行詞的語料。若使用教學自擬句，必須明示「教學例句」，不得冒充古籍原文。

## 建議執行順序

1. 先改上述 14 題，加上最短必要語境；同步修正 `p2q043` 的說話者誤標。
2. 再審全部主線指代、施事者追蹤、省略補足題，逐題記錄答案在題內的證據。若不能明確指出，先補文或改問法。
3. 審核主線新知的提示與示例，讓「首次遇到詞義」和「已教後的驗證」有所區分；優先利用既有微課堂內容。
4. 繼續審語意辨析、句序、翻譯與短段閱讀，減少只靠術語及熟句重複的題目。
5. 課文記憶題持續與主線分開。學習單位以詞義、虛詞、語序、指代、句意和遷移能力組織，篇名作語料來源。

## 改題時的資料與驗證原則

- 補足語境但評量目標不變時，保留題目 ID 與技能映射，記錄修訂；若改變答案或評量目標，須另行處理舊紀錄及錯題重試，不宜直接覆蓋。
- 舊題資料不足造成的作答錯誤不應被解讀成新的能力不足；先盤點既有紀錄影響，再決定修復方式，不在初審時批量刪除學習紀錄。
- 純語境補充應做內容與答案唯一性核對；涉及答案、接受答案或技能目標改動時，需同步處理伺服器權威題庫與產物。
- 驗證重點是學生看得到的題面、可指認的文本證據，以及另一個語境能否驗證同一技能。通過程式測試不能取代教學內容審核。
